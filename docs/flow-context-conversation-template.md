# Flow Context demo conversation template

Fill a copy of this file and attach the `.md` or `.txt` file in chat. All the material can be synthetic. Write the conversations in the order they happened; approximate dates or `Day 1`, `Day 2` are fine. One file can contain the whole thread.

```text
Thread: [short name for the problem]
Material: synthetic

## Conversation 1
When: [date or Day 1]
Source: [ChatGPT / Claude / voice thought / meeting / document / other]

Me: [what you said or wrote]
ChatGPT: [what the AI replied]
Me: [your reaction, especially if you changed or rejected an idea]

## Conversation 2
When: [date or Day 2]
Source: [source]

Me: [text]
Other person: [text, if applicable]

## Conversation 3
When: [date or Day 3]
Source: voice thought

Me: [text]
```

Keep each speaker's words in a separate turn. A voice thought can be a single `Me:` turn. For meeting notes without a transcript, write `Meeting notes (paraphrase): ...` instead of inventing quotes. Include the moment you changed your mind and the question that remains open if those are part of the story.

You do not need to add IDs, source citations, stance labels, or JSON. I will convert the file into the service's local data format and mark every record as synthetic. The file is input to the demo, not something Handy or the service will automatically fetch from ChatGPT.
